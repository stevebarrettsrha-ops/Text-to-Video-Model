The cut

One card per shot. A chained shot starts on the previous shot's last frame, so faces and places carry through the whole cut — the tag on each card turns that off. Drag cards to reorder. Size, steps and the rest come from the generator's Settings.
Library

Weights

A MiniMax H3 set is five files: the ref2va model, the Qwen3-VL-32B text encoder, a video VAE, an audio VAE, and the turbo LoRA. The sizes shown are the real ones — check them against the preflight on the Engine page before starting a download.

H3 is under the MiniMax community licence. If a download is refused, accept it on the model page and add a token below.
